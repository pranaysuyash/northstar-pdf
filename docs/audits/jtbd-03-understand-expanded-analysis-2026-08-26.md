## 21. SO WHAT

### 21.1 The Fundamental Insight

**Understanding is the biggest gap in our product.** We render pixels well, but we don't help users comprehend content. This is where the real value lies.

**The gap:** We're a **viewer** (renders PDF bytes into pixels). Users need a **comprehension tool** (helps them understand, extract, and act on content).

### 21.2 What This Means

| Dimension | Current | Needed | Gap |
|---|---|---|---|
| Structure display | Basic outline | Rich navigation | LARGE |
| Content extraction | None | Summaries, tables | LARGE |
| Entity recognition | None | Dates, amounts, names | LARGE |
| Key point extraction | None | Important content | LARGE |
| Version comparison | None | Diff view | LARGE |
