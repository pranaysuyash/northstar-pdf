Deficiencies in Before Architecture (MAD-I6)

  • Cognitive Saturation: 13 distinct buttons + 3 segmented pickers in one horizontal row create visual claustrophobia.
  • Intent Misalignment: Viewport controls (zoom, view mode) fight for priority with irreversible mutation tools (sanitize, batch merge).
  • 2004 Utility Syndrome: Flat gray chrome resembles legacy desktop tools rather than modern spatial macOS Tahoe/Sequoia design.
  • Window Shrink Traps: Resizing window under 1000px wraps or clips critical actions into overflow chevrons.

First-Principles Benefits in After Architecture

  • Intent-Centric Islands: Mode Switcher & Ask Northstar HUD reside in top glass pill; Canvas Navigation floats at bottom; Export docks top-right.
  • Document-First Elevation: 38px of dead vertical toolbar chrome reclaimed for true PDF page real estate.
  • Material Hierarchy: High-contrast hairline borders with .ultraThinMaterial ensure readability in both dark and light modes.
  • Assistive Tech Parity: Full VoiceOver labels and keyboard shortcuts (⌘K, ⌘Z, ⌘+, ⌘-) preserved without reliance on raw symbol names.
