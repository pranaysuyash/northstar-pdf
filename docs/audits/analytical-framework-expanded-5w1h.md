# Expanded Analytical Framework — Beyond 5W1H

**Date:** 2026-08-26
**Purpose:** First-principles analysis framework for understanding any job, feature, or system
**Scope:** 20+ dimensions for complete analysis

---

## 1. The Framework

Traditional 5W1H (Who, What, When, Where, Why, How) is insufficient for serious analysis. We need **20+ dimensions** to capture the full picture.

---

## 2. Core Dimensions (5W1H)

### 2.1 Who
**Who is involved?**

| Dimension | Question | Example |
|---|---|---|
| Person | Who is the primary actor? | Student, lawyer, executive |
| Actor | Who performs the action? | User, system, automation |
| Stakeholder | Who is affected? | Author, reviewer, approver |
| Role | What role do they play? | Reader, editor, signer |
| Expertise | What do they know? | Expert, novice, intermediate |

### 2.2 What
**What is happening?**

| Dimension | Question | Example |
|---|---|---|
| Thing | What is the object? | PDF document, form, contract |
| Action | What is being done? | Reading, searching, filling |
| Event | What triggered this? | User request, system event |
| Outcome | What is the result? | Comprehension, decision, signature |
| Artifact | What is produced? | Annotation, filled form, signed doc |

### 2.3 When
**When does this happen?**

| Dimension | Question | Example |
|---|---|---|
| Time | What time of day? | Morning, during meeting, late night |
| Date | What date? | Today, this week, this quarter |
| Sequence | What order? | First, middle, last |
| Duration | How long does it take? | 5 minutes, 1 hour, all day |
| Frequency | How often? | Once, daily, weekly |

### 2.4 Where
**Where does this happen?**

| Dimension | Question | Example |
|---|---|---|
| Place | Physical location? | Office, home, commute |
| Platform | Digital location? | Desktop, mobile, web |
| Context | Situational context? | Work, personal, education |
| Environment | Physical environment? | Quiet, noisy, shared space |
| Network | Network context? | Online, offline, restricted |

### 2.5 Why
**Why is this happening?**

| Dimension | Question | Example |
|---|---|---|
| Reason | What's the reason? | Need information, must complete |
| Cause | What caused this? | Boss request, deadline, curiosity |
| Motivation | What motivates? | Career, grades, compliance |
| Goal | What's the end goal? | Learn, decide, approve |
| Value | What value does it create? | Knowledge, efficiency, compliance |

### 2.6 How
**How is this happening?**

| Dimension | Question | Example |
|---|---|---|
| Method | What method is used? | Reading, searching, skimming |
| Process | What's the process? | Open → read → annotate → save |
| Mechanism | What mechanism? | Visual, auditory, kinesthetic |
| Tool | What tool is used? | PDF reader, browser, printer |
| Technique | What technique? | Linear, random, search-first |

|---|---|---|

## 4. Quantity Dimensions (How much/many/often/long/far)

### 4.1 How Much
**What's the quantity?**

| Dimension | Question | Example |
|---|---|---|
| Cost | What's the cost? | Time, money, effort |
| Value | What's the value? | Benefit, ROI, importance |
| Risk | What's the risk? | Probability × impact |
| Effort | How much effort? | Minutes, hours, days |
| Resources | What resources needed? | CPU, memory, network |

### 4.2 How Many
**What's the count?**

| Dimension | Question | Example |
|---|---|---|
| Items | How many items? | Pages, fields, annotations |
| Users | How many users? | One, team, organization |
| Documents | How many documents? | Single, batch, corpus |
| Versions | How many versions? | One, multiple, history |
| Iterations | How many iterations? | Once, loop, until done |

### 4.3 How Often
**What's the frequency?**

| Dimension | Question | Example |
|---|---|---|
| Rate | How often per time? | Daily, weekly, monthly |
| Pattern | What's the pattern? | Regular, sporadic, burst |
| Trigger | What triggers it? | Time, event, condition |
| Predictability | Is it predictable? | Scheduled, random, on-demand |
| Seasonality | Is there seasonality? | Tax season, quarterly, annual |

### 4.4 How Long
**What's the duration?**

| Dimension | Question | Example |
|---|---|---|
| Session | How long per session? | 2 min, 30 min, 2 hours |
| Task | How long per task? | Quick, medium, complex |
| Process | How long total? | Minutes, hours, days |
| Waiting | How long to wait? | Instant, seconds, minutes |
| Retention | How long to remember? | Session, days, forever |

### 4.5 How Far
**What's the scope?**

| Dimension | Question | Example |
|---|---|---|
| Distance | How far reach? | Local, network, global |
| Scope | How broad scope? | Single page, document, corpus |
| Depth | How deep analysis? | Surface, detailed, exhaustive |
| Breadth | How wide coverage? | One type, all types, universal |
| Impact | How far impact? | Local, team, organization |

## 10. The Meta-Insight

**The framework is recursive.** Each dimension can be broken down further using the same framework.

**Example:** "Who" can be broken down into:
- Who (person)
- Who (actor)
- Who (stakeholder)
- Which who (selection among alternatives)
- Whose who (ownership)
- Whom who (affected party)
- How many who (count)
- How often who (frequency)
- etc.

**This is the power of first-principles analysis:** You can keep drilling down until you reach fundamental truths.
